# MIDI implementation (0.6.4)

The engine answers MIDI as a Yamaha XG tone generator does, as far as an
orchestra of physical models can. Each part listens on its own channel (part 1
on channel 1, and so on). The code is `app/orch_cc.c`, and its value laws are in
`app/orch_cc_tables.inc`, generated by `tools/gen_cc_tables.py`.

Every one of the 128 values does something: levels move in even dB steps, times
and rates on a log scale, and choices in equal zones.

## Playing controllers

These are per part, take effect immediately and glide over about 3 ms, so a
fast sweep does not step. They are not saved.

| Message | Does | Law, reset value |
| --- | --- | --- |
| Note on velocity | how hard the note is played: brighter and louder | even dB over 32 dB (1 measures −34.5 dB from 127; 0.6.3 had −63 dB, with the bottom 16 steps nearly silent) |
| Pitch bend | the loop's length, so the pitch | ±2 semitones; RPN 0 sets 0..24 |
| CC1 modulation | vibrato on the part's own LFO (rate CC76, delay CC78), on top of the part's LFO setting | 0..±50 cents, reset 0 |
| CC2 breath | how hard it is bowed or blown: level (even dB over 30 dB) and drive (half to full, so softer is darker) | 127 |
| CC7 volume | part level | GM2/XG curve, 40·log10(v/127) dB; **power-on 100** (−4.2 dB) |
| CC10 pan | balance on the part's seat (the stage places it; 64 leaves it there) | 64 |
| CC11 expression | part level | GM2/XG curve; 127 |
| CC64 sustain | hold | |
| CC67 soft pedal | −2.5 dB and a little darker while down | off |
| CC74 brightness | the strings' and bores' damping | relative, 64 = the instrument, ±1.5 steps |
| CC120, CC123..127 | all sound off, all notes off, mode messages | |
| CC121 | reset controllers: expression, breath, modulation, brightness, soft, bend, RPN (as XG; volume and pan are kept) | |

## Settings (the same ones the panel turns, so SAVE keeps them)

As on XG, the sound controllers are **relative**: 64 gives the instrument's own
value, 0 the shortest or least, and 127 the longest or most.

| Message | Does | Range |
| --- | --- | --- |
| CC0 bank select MSB + program change | bank 0 keeps the part's family; banks 1..5 choose strings, woodwinds, brass, mallets, choir. The program chooses the instrument in the family and wraps around | |
| CC71 harmonic content | the shared resonance (it belongs to the whole hall, so any channel can set it) | 0..100, 64 = 25 |
| CC72 release | | 1..6000 ms, log |
| CC73 attack | | 1..4000 ms, log |
| CC75 decay | | 1..4000 ms, log |
| CC79 | sustain level (XG leaves this controller free) | 0..100 % |
| CC76 vibrato rate | the part's LFO rate | 0.1..20 Hz, log, 64 = 5 Hz |
| CC77 vibrato depth | the part's LFO depth; above 64 it also turns pitch on | 64 = the part's own (0) |
| CC78 vibrato delay | | 0..5 s, log |
| RPN 0 (CC101/100 = 0/0, CC6, CC96/97) | pitch bend range | 0..24 semitones |
| CC14 | articulation in 12 equal zones of about 11 values: auto, portamento, legato, détaché, martelé, staccato, spiccato, pizzicato, flageolet, tasto, ponticello, col legno (XG has no articulation controller) | |
| CC15 | players per part 1..4 (no XG meaning) | |

## Effect sends

The effects belong to the whole hall: every channel's send reaches them. They are
one insert after the mix, not a send per part as on XG. Value 0 switches the
effect off, and 1..127 switch it on at a mix of 1..100 %.

| CC | XG | Here |
| --- | --- | --- |
| 91 | reverb send | REVERB (shimmer) |
| 93 | chorus send | CHORUS |
| 94 | variation send | DELAY |
| 95 | — | ENSEMBLE |
